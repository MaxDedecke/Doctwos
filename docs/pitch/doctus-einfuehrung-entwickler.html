Doctus

Fragen an den eigenen Code. Antworten mit Beleg.

Für das Team hinter SecDocs und DSEngine

Doctus liest euren Code, eure Wikiseiten und Issues und beantwortet Fragen dazu mit Verweis auf die Originalstelle.

Ein ganz normaler Dienstag

Jede Quelle kennt einen Teil der Antwort, aber keine kennt die Zusammenhänge zwischen ihnen.

Das Wissen ist da. Es liegt nur verteilt.

Doctus verbindet die Quellen, die ihr ohnehin pflegt, statt ein weiteres System zum Befüllen einzuführen.

Ihr kennt die Bausteine schon

  • git fetch→Git-Quelle
  • Compiler, AST→Parser
  • Find Usages→Code-Graph über alle Repos
  • grep→Suche nach Bedeutung
  • Merge Request→Erkenntnis mit Freigabe
  • CI-Pipeline→Änderungspaket
  • docker compose→Betrieb im eigenen RZ

Neu ist vor allem, dass diese Werkzeuge über alle Repos, Wikis und Issues hinweg zusammenarbeiten.

Suchen nach Bedeutung

Wie wird ein Beweisdatensatz erneuert?

Keiner der drei Treffer enthält das Wort „Beweisdatensatz“. Ein Embedding-Modell bildet jeden Textabschnitt auf 1.024 Zahlen ab, und ähnliche Bedeutung liegt nah beieinander, auch zwischen Deutsch und Englisch.

Wie eine Antwort entsteht

Das Modell kennt euren Code nicht. Es liest nur das Belegpaket. Der eigentliche Wert liegt im Zusammenstellen dieses Pakets, das Formulieren ist der kleinere Schritt.

Nur freigegebene Erkenntnisse, deren Belegcode sich seither nicht geändert hat, fließen in Antworten ein.

Beweiswert, auf Code angewendet

Wie ein Evidence Record einen Hash an einen Zeitpunkt bindet, bindet eine Erkenntnis ihre Belege an einen Commit.

Was berührt mein Commit?

Doctus startet selbst keinen Build. Eure Pipeline meldet Maven- und Testergebnisse mit einem quellengebundenen Token, und Doctus hängt sie an genau diesen Commit.

Auch Coding-Agenten fragen Doctus

Agenten in IDE oder Terminal nutzen Doctus über das Model Context Protocol und bekommen dasselbe Belegpaket wie der Chat.

Läuft bei euch, nicht in der Cloud

Jede Person sieht nur ihre Projekte. Der Chat auch. Alle Dienste laufen per docker compose im eigenen Netz, auch offline und nur mit Open-Source-Lizenzen.

Was Doctus nicht ist

  • ✕ Ersatz für Review und Tests
  • ✕ noch ein Wiki zum Pflegen
  • ✕ Code-Generator
  • ✕ Orakel ohne Beleg

Doctus verkürzt den Weg zu den richtigen Stellen, die Entscheidung bleibt bei euch.

Probiert es aus

  • Eine echte Frage aus dieser Woche stellen.
  • Auf die Quelle klicken.
  • Prüfen. Fehler melden.

Je echter die Frage, desto mehr lernen wir alle aus der Antwort.
